FOG-MOS

MATLAB implementation of the paper:

Flexible Optimal Graph with Multi-Order Similarity for Unsupervised Domain Adaptation

Requirements
MATLAB
Usage

Run:

demo_office_caltech10_surf

The demo evaluates FOG-MOS on the Office+Caltech10 dataset using SURF features.

Files
FOG_MOS.m: Main implementation of FOG-MOS
demo_office_caltech10_surf.m: Demo script
util/: Utility functions
data/: Experimental data
